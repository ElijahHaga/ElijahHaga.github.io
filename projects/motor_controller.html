Motor Controller Project

This is a motor controller I deisgned at my internship this summer at Adom Industries. I was put in charge of designing the electronics system for the autonomous robot shuttles the company was desiging, and one of circuit boards I designed for this project was a motor controller board. It can handle 30 Amps at 60 Volts, and is capable of using either the built-in magnetic rotary encoder or an external encoder that uses SPI or I2C. It can communicate over CAN using CAN-FD. I designed the board to be able to use some pre-made open-source firmware, but I had to make some major changes to the firmware to allow for faster CAN communication and to enable the built-in rotary encoder to work. This gave me a lot of experience of programming firmware in C and flashing it to the STM32.
