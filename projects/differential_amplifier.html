Differential Amplifier (Final Project for 6.2080, Semi-Conductor Circuits)

This is a differential amplifier and supporting hardware that I designed and simulated for 6.2080, a class on semi-conductor circuits at MIT. The class covers the design and physics behind diodes and MOSFETs, how they operate in different topologies, and their simulation and design in Cadence. The final project for the class is to design and simulate a differential amplifier with a gain over 26 dBm and voltage swing higher than 300mV, as well as the supporting hardware, including transmission gates and a code checker (a circuit that checks if the input code matches the assigned code and outputs a signal accordingly). Because the class is supported by TSMC, who manufacture the chips for us, I cannot share any of the files, designs, simulations, or layouts for this project, apart from the thumbnail image shown above.
