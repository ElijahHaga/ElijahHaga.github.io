Gameboy Color Cartridge

This PCB is a Gameboy Color Cartridge circuit board that I reverse-engineered. I researched the parts in the original cartridges, recreated them in modern 3D models and footprints, and arranged them in the same positions they were in in the original cartridges, but I routed the traces and placed the copper pour to my own design. It uses an MBC5 chip to map storage to an MX23C8005-12 read-only memory (ROM) to store the game files, and a W24257S-70LL random access memory (RAM) chip to store the save states for the player. It also has a MM1134A as a backup IC. It interfaces with the Gameboy Color using a 32-pin card edge slot. I used Altium Designer and the Celestial Altium Library, a free online library of components for the simpler electronics of the circuit board (like capacitors and resistors), although I designed the main chips of the board myself. This was another project that I did to improve my ECAD skills and to practice reverse engineering of circuit boards.
