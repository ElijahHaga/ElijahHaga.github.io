Time of Flight Sensor Board

I designed this time-of-flight sensor board for my internship at Adom Industries over the summer for use in the design of their autonomous robot shuttles. It uses the VL53L8CXV0GC/1 time of flight sensor from STMicroelectronics in SPI mode to communicate with the main robot computer, a Raspberry Pi 4B running ROS2. I used it to help determine the height of the lift mechanism on the robot shuttle, which used a scissor lift to retrieve items from shelves in a warehouse. The circuit board has to include a level shifter because the VL53L8CXV0GC/1 operates on +1.8V while the logic from the Raspberry Pi is +3.3V.
