This Page!

I created this portfolio to apply for internships. However, I did not want it to be a boring, typical portfolio, so I designed the whole thing using GitHub Pages, which allows you to have one free webpage per GitHub account. This meant that I had to learn website programming, which I had never done before. Creating the typical HTML elements was quite easy; the real challenge started with using CSS and JavaScript to style my webpage, including the project cards on the homepage and the slides of images available for some of the projects. However, through documentation online, I was able to figure these elements out and make my webpage more interesting.
