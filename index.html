This Page!

I created this portfolio to apply for your internship. However, I did not want it to be a boring, typical portfolio, so I designed the whole thing using GitHub Pages, which allows you to have one free webpage per GitHub account. This meant that I had to learn website programming, which I had never done before. Creating the typical HTML elements was quite easy; the real challenge started with using CSS and Javascript to style my webpage, such as creating the image carousels and the button that toggles the paper I wrote on batteries. However, through documentation online I was able to figure these elements out and make my webpage more interesting. P.S. I know VSCode says there's an error in the style.scss file, but there is not, the part that is raising an error is what allows the webpage to access the file.
